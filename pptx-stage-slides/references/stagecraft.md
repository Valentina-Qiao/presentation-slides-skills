# 通用固定舞台工艺与避坑（模板无关）

适用于任何已确认 theme spec 的 16:9 HTML 演讲页。颜色字体一律走 `:root` 变量，本文只讲结构、几何与流程纪律。

## 1. 舞台、缩放与安全区

- `.stage{width:1280px;height:720px;position:relative;overflow:hidden}`，`body` flex 居中、深色底；舞台 `transform:scale(s)` 等比适配，`s=Math.min(innerWidth/1280,innerHeight/720)`，不变形不裁切。
- 内容页 `.body{height:calc(720px-顶栏高);padding:...}`，**内容安全高度约 580px、宽约 1188px**；新增纵向区块后按预算求和并留 ≥30px 余量，不许顶满。
- 所有颜色用 `:root` CSS 变量（主色/墨色/灰/浅底/描边），换模板只改变量与少量组件几何，不逐页找色值。

## 2. 幻灯片显隐铁规则

特殊 display 的 slide 变体必须显式声明非激活态，否则会多页叠加重影：
```css
.slide{position:absolute;inset:0;display:none;}
.slide.active{display:block;}
.slide.chapter{display:none;}
.slide.chapter.active{display:grid;}
.toc .chapter{display:grid;}   /* 目录内章节块常驻 */
```
以后新增任何带特殊 display 的 slide 类型，同时补它的非 active `display:none`。

## 3. 翻页接口契约（PDF 脚本依赖）

骨架必须暴露全局 `slides`（Node 数组）、`show(i)`、`cur`，舞台元素 id 为 `stage`：
- `show(i)` 切换 `.active` 并更新计数器；总数用 `slides.length` 自动算。
- 绑定左右方向键与按钮；counter 静态占位初始写成 `1 / N` 并由脚本覆盖。
`export_pdf.py` 依赖这些同名接口逐页截图，勿改名。

## 4. 防溢出（返工最多，按确定性方法做）

- 不要靠"字号×行数"心算高度：中文实际行高、flex 拉伸、意外折行都会让估算偏小。
- 优先紧凑栅格+小卡、统一分区小标题；信息超量先拆页或合并同主题，不靠无限缩字号，更不许裁切或删掉用户文字。
- **复杂流程图/信息量大的竖向图，优先用高清原图**：固定高度容器（如约 508px，依安全区调整）+ `img{max-height:100%;max-width:100%;object-fit:contain}`，浏览器强制等比，数学上保证不溢出。竖图进宽屏自然居中留边，不要拉伸。
- 自绘泳道/流程仅在高度预算确定充裕时使用，并给容器可核算的固定/上限高度。

## 5. 关系、箭头与虚线

- 并列模块（同层级、可换序的方面/维度）之间**禁止箭头**，等高独立成卡；判断方法见 ppt-content-blueprint 的关系决策表。
- 箭头只用于：时间/步骤流程（单向、方向一致）与卡片内部推导（证据→启示、风险→对策）。
- 实线=正式内容/主流程；**虚线 dashed 仅用于未来工作、非本期实现、局限/风险**，并配文字明确标注，勿把规划项画成已完成。

## 6. 文案、数据与对齐纪律

- 只重组不阉割：不删、不改写、不弱化用户确认过的文案；空间不够改布局，删字先问；要求回退版本时原样回退再只改指定点。
- 数据可追溯：每个数字对得上源材料，标国别/范围、年份、来源、口径与可比性；专业名词附解释；来源脚注放页底最小灰字。
- 三级文字层级：页标题（结论句）＞卡主词（加粗主色）＞说明副文（小灰字），同级字号字重统一；每卡加粗点克制（2–3 处）。
- 对称等高：并列卡统一栅格列数与 padding、内部分区基线对齐；列数避免末行孤卡（如 4 卡不排成 3+1）；同功能区块跨页复用同一 class。
- 材料以最新版为准（方法数量、技术路线口径等可能更新），不沿旧版；拿不准"第 N 页"指哪张时按页名与用户确认，不臆断。

## 7. 图片、编码与页码

- 云电脑图片必须 `lark-cli drive +html-image-upload` 换不过期 URL，禁用 FileBatchUpload；图不显示先查 src 是否过期重传。
- 文件存 UTF-8（可带 BOM），保留 `<meta charset="utf-8">`；中文乱码先排查是否第 2 节的显隐叠加，勿盲目转码。
- 增删页后：顺移右下角方块页码（封面/章节/收尾常无方块）、同步 counter 的 `1 / N`、检查 section 开闭配平与导航当前项高亮。
- 单文件自包含：CSS/JS 全内联、原生 JS、不用框架；只交付一个 .html。

## 8. 交付前检查清单

- [ ] 任意时刻只显示当前页，无章节/目录重影。
- [ ] 无元素超出 1280×720；内容区不超约 580px 高，留有余量。
- [ ] 并列卡间无箭头；虚线仅用于未来/局限；流程箭头方向一致。
- [ ] 用户文案未被删改；数据口径齐全、名词有解释。
- [ ] 图片均为不过期 URL 且仅用 src 引用，无裂图。
- [ ] 页码连续、总页数正确、section 配平、导航高亮正确、UTF-8 正常。
- [ ] 颜色字体全部来自已确认的 theme spec，未临时换色。
- [ ] 用户确认 HTML 后再导出 PDF，只交付一个最终 .html。
