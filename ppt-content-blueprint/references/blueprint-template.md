# 逐页蓝图：字段 Schema 与范例

正式产出蓝图时逐页填下面的字段。字段顺序固定，缺项写"无"，不要删字段，便于表现层 Skill 稳定消费。

## 1. 蓝图字段 Schema

### 文档级头信息（整份蓝图一份）
- 题目 / 副标题
- 场景与时长：如开题答辩 3–5 分钟
- 目标页数区间与实际页数
- 章节划分（编号 + 名称），列出哪些是封面/目录/章节过渡/收尾的非内容页
- 全局口径约定：数据年份、来源清单、术语表、主色与品牌（若已知；视觉细节留给表现层）

### 单页字段（每页一组）
| 字段 | 填什么 |
|---|---|
| page_no | 逻辑页码；标注是否章节过渡/收尾（这些页通常无方块页码） |
| nav | 所属一级章节（对应顶部导航/目录高亮） |
| page_type | 取自页型库（背景/意义/综述/方法/技术路线/实验/风险/进度/成果…） |
| title | 结论句页标题 + 可选英文副题 |
| key_message | 这一页一句话核心结论（口播主线） |
| points | 要点数组；每条标 `bold`（加粗主词）、`data`（数字+口径）、`term`（名词+解释）、`note` |
| relation | 模块关系：并列 / 流程 / 因果 / 对照 / 层级，并写明箭头出现位置 |
| elements | 建议表达元素（KPI 卡/条形图/时间轴/配对卡/虚线框…）与栅格列数、卡片数 |
| source | 数据来源、年份、统计口径、可否横向比较 |
| boundary | 非本期/未来工作/局限等边界说明 |
| remark | 合并页说明、待用户确认项、口播提示、防溢出提醒 |

关系与元素的判定规则见 `page-patterns.md`。蓝图阶段不写颜色像素，只写"建议用 KPI 卡/并列卡"这类语义元素。

## 2. 完整范例（节选自一份保险素养开题答辩，演示填法）

### 文档头
- 题目：对话式 AI 对居民保险素养的影响研究——基于"保险小白助手"的前后测实验
- 场景：开题答辩 3–5 分钟；目标 14–16 页
- 章节：01 研究背景与意义 / 02 研究目标与思路 / 03 研究过程与分析 / 04 研究结论与展望
- 术语：保险深度＝保费÷GDP；保险密度＝人均保费
- 口径：中国数据用 2025 年金监总局；美日用瑞士再保险 sigma 最新完整年份(2024)，币种不同仅纵向对照不横向折算

### 单页范例 1：研究背景（page_type=背景）
- title：研究背景与问题提出
- key_message：市场体量大但居民素养不足，传统科普与现有 AI 都有缺口，本研究切入纯科普对话式 AI。
- points：
  - KPI 四连（均标 data，口径标签"中国·2025"）：原保险保费收入 6.12 万亿元；保费规模全球第 2；保险深度 4.4%；保险密度 4356 元/人
  - term：保险深度＝保费÷GDP；保险密度＝人均保费
  - 三类居民误区（并列标签）：态度层"保险是骗人的/理赔难"、知识层"社保够用/不如理财"、意愿层"先给老人孩子买/熟人不看条款"
  - 手段缺口：传统图文单向、互动弱；市面 AI 多为产品推荐；本助手只做科普不推荐产品
- relation：三组误区为**并列**，误区之间无箭头
- elements：4 张 KPI 卡 + 中美日深度条形图与迷你对照表 + 名词解释 + 误区红色标签 + 底部"传统图文/现有 AI/本研究"三色对照条；页底来源脚注
- source：金监总局 2025、sigma 2024、2025 消费者金融素养调查（44.85% 认知缺口）
- remark：数字一律带来源年份；明确是中国数据还是中外对照，不让读者猜口径

### 单页范例 2：国内外研究现状（page_type=文献综述）
- title：国内外研究现状和发展趋势
- key_message：三条线索各有进展，但"保险领域×中国情境×针对具体误区"的干预检验仍缺，正是切入点。
- points（三条并列线索，每条一卡）：
  - LINE01 素养测量与保险决策：Lusardi & Mitchell 客观知识题开创；国内基于 CHFS 微观数据；多为截面相关、难识因果 → 卡内启示：指导判断题题项设计
  - LINE02 误区、信任与购买行为：柠檬市场/信息不对称；计划行为理论解释投保意愿 → 卡内启示：知识态度意愿三维度分开测、不合并
  - LINE03 对话式 AI 教育效果：多轮对话助知识内化；聊天机器人实验提供分组操纵模板；正向但受条件约束 → 卡内启示：保险领域×中国情境×具体误区的检验缺乏
- relation：三条 LINE **并列，卡间严禁箭头**；每张卡内部"现有证据→对本文启示"允许卡内箭头
- elements：3 张等高并列卡（LINE 01–03）+ 学者小标签 + 卡底红色"对本文的启示"块；底部"总结"条（不叫"研究述评"）
- remark：用户要求保留完整长文案时不得擅自删改；三卡文字自然弹性布局但须等高对齐

### 单页范例 3：技术路线（page_type=技术路线）
- key_message：同一题库"一源两用"，同时生成测量问卷与干预 Agent 知识库；RAG 仅未来升级。
- points（六阶段流程）：研究目标 → 题库构建(理论准备/实证准备→素养题库) → 工具开发(测量工具/干预工具 ⇢ 虚线未来扩展 RAG) → 准实验(统一前测→助手组/图文组→统一即时后测) → 数据分析(组间检验/变化估计/分维度指标) → 结论与建议
- relation：整体是**流程**，阶段间单向箭头；阶段内理论/实证、助手/图文为并列
- elements：左竖排阶段标签 + 右侧虚线分组框 + 空心向下箭头；"未来扩展 RAG、非本期"用虚线框+虚线箭头
- boundary：RAG 检索增强、拓展科普专题为未来工作，明确标"非本期实现"
- remark：流程图必须完整落在一屏内；若 HTML 自绘高度不可控，可改用高清原图 contain 锁高防溢出

### 单页范例 4：数据分析·可行性·风险（page_type=风险）
- key_message：主方法可重复、可行性有据、每个风险都有对应对策。
- points：
  - 主方法条：知识得分用协方差分析(后测=因变量、分组=因子、前测=协变量)
  - 方法小卡（并列）：次要结果分开报 / 报告差值·95%CI·效应量 / 非正态转非参数
  - 可行性卡（并列 5）：理论成熟、技术可控、样本可得、方法基础、时间保障
  - 风险→对策配对（5 对）：样本不足→预留 20% 冗余并报功效；态度意愿不显著→分开检验照实报；社会期望偏差→匿名+反向计分；基线不均→协方差控前测；AI 输出波动→结构化条目+人工审定+锁版本+留痕
- relation：可行性各卡**并列**；风险与对策是卡内**配对推导**，箭头在卡内
- elements：方法强调条 + 3 方法卡 + 5 可行性卡 + 风险配对卡网格（末项跨列）
- remark：原报告大段文字必须拆成卡片，禁止整段平铺；控制在一屏
